Quantum Teleportation State Explorer — Python Source Code

This page displays the desktop Python version of the Quantum Teleportation State Explorer. The application uses Python, Tkinter, NumPy, SciPy, Matplotlib, and QuTiP to study continuous-variable quantum teleportation, Wigner-function diagnostics, noisy teleportation channels, and constrained optimization of Fock-basis quantum states.
