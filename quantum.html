Quantum Dynamics

Kerr Nonlinearity and Wigner Function Evolution

\[ i\hbar \frac{\partial}{\partial t}|\psi(t)\rangle = \hat{H}|\psi(t)\rangle \]

This page presents a visualization of the Wigner function evolution of a coherent state under Kerr nonlinearity. More Hamiltonians and animations can be added later as separate sections.

Kerr Nonlinearity

Kerr Hamiltonian

\[ \hat{H} = \omega\left(\hat{n}+\frac{1}{2}\right) + \chi \hat{a}^{\dagger}\hat{a}^{\dagger}\hat{a}\hat{a} \]

The Kerr Hamiltonian describes a nonlinear optical system where the energy shift depends on the photon number. The first term corresponds to the ordinary harmonic oscillator contribution, while the second term introduces the nonlinear Kerr interaction.

Since \[ \hat{a}^{\dagger}\hat{a}^{\dagger}\hat{a}\hat{a} = \hat{n}(\hat{n}-1), \] the nonlinear part gives a photon-number-dependent phase evolution. This means that different number-state components of the initial state evolve with different phases.

Initial Coherent State

The initial state used in the animation is a coherent state. In the photon number basis, it can be written as

\[ |\alpha\rangle = e^{-|\alpha|^2/2} \sum_{n=0}^{\infty} \frac{\alpha^n}{\sqrt{n!}} |n\rangle . \]

In the simulation, the coherent state is created using \(\alpha=\sqrt{\bar{n}}\), where \(\bar{n}=5\). Therefore, \(\alpha=\sqrt{5}\), and the state has an average photon number of 5.

Physical Interpretation

A coherent state initially has a Gaussian-like Wigner function in phase space. Under Kerr evolution, the nonlinear photon-number-dependent phases distort this distribution. As time progresses, the state develops interference structures and nonclassical phase-space features.

\(\omega\): oscillator frequency

\(\chi\): Kerr nonlinear coupling strength

\(\hat{a}, \hat{a}^{\dagger}\): annihilation and creation operators

\(\hat{n} = \hat{a}^{\dagger}\hat{a}\): photon number operator

\(|\alpha\rangle\): coherent state

\(|n\rangle\): photon number state
